# Student Performance: A Statistical Analysis

## Overview
This beginner-friendly portfolio project uses Python to explore a small synthetic dataset of student study hours, attendance, and marks.

## Objectives
- Summarize data using descriptive statistics.
- Visualize the distribution of marks.
- Explore associations using scatter plots and Pearson correlation.
- Fit a simple linear regression model.
- Calculate Mean Squared Error (MSE).

## Tools
Python, Pandas, NumPy, Matplotlib, SciPy, Jupyter Notebook.

## Dataset
The notebook creates a small synthetic dataset for demonstration. It is not real student or institutional data.

## How to run
1. Open the `.ipynb` file in Jupyter Notebook or Google Colab.
2. Run the cells from top to bottom.
3. If needed, install the libraries with:
   `pip install pandas numpy matplotlib scipy`

## Important limitation
This is a learning demonstration using a small synthetic dataset. It should not be used to make claims about real students. Correlation does not prove causation.
